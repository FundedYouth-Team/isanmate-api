# Public API Model

## Intro

I am a wholesaler for iSANMATE. They do not have an official public API. I have reached out to their team and they have confirmed that they do not have a public API but they are okay with us building a public one for them.

## Public API

To build this API. We need to scrape the isanmate.store website. Including the endpoint isanmate.store/collection/all and https://isanmate.store/search

For this initial API, we will create a JSON file that will store all of their inventory listed on their online store. Listing the name, roll size, price, colors, material type, etc. This should also include image links, product page link and product description.

Their contact that is working with me has confirmed that the e-commerce store is built using Shopify.

## Advanced API

Once the initial json data file is creted. I would then like to build out a user friendly tool or web app that lets me click an update button which then updates data json file.
